# 🏠 Home Assistant Helpers & Scripts

Zentrale Sammelstelle für eigene Home Assistant Custom Cards, Automatisierungen, Skripte und Templates.

## 📁 Struktur

- **[`cards/`](cards/)**: Lovelace Custom Cards
- **[`automations/`](automations/)**: Wiederverwendbare YAML-Automatisierungen & Blueprints
- **[`scripts/`](scripts/)**: Python-, Shell- und Wartungsskripte
- **[`templates/`](templates/)**: Jinja2 Template-Sensoren & Helfer

## 📦 Karten

- [**Spotify Show Card**](cards/spotify-show-card/README.md): Bildschirmfüllender Touch-Player für Echo Show & Tablets mit dynamischen Cover-Farben, interaktiver Seekbar und Lautstärkeregler.
